# The CPH-NG Project

> [!WARNING]
> **Rust 重构进行中：当前构建版本不可用。** `main` 分支及其 GitHub Actions 自动构建产物尚不能用于日常使用；构建成功不代表功能已恢复。请继续使用重构前的稳定发布版本，并等待恢复可用的通知。
>
> **暂停接受与 Rust 重构无关的新 PR。** 重构期间仅接受直接支持 Rust 内核迁移、集成和验证的 PR；其他新功能、修复及常规依赖更新 PR 请待重构完成后再提交。
>
> 背景见此前的[内核 Rust 重构及维护调整公告 #285](https://github.com/langningchen/cph-ng/discussions/285)。如公告所述，欢迎参与 Rust 重构；与重构无关的 PR 恢复受理时间将另行通知。
>
> **Rust rewrite in progress: current builds are unusable.** The `main` branch and its GitHub Actions artifacts are not ready for everyday use, even when CI passes. Please use a stable release from before the rewrite until availability is announced.
>
> **New PRs unrelated to the Rust rewrite are temporarily not accepted.** Only PRs directly supporting Rust kernel migration, integration, and validation are accepted during this period. Please defer unrelated features, fixes, and routine dependency updates until the rewrite is complete.
>
> See the earlier [Rust rewrite and maintenance announcement #285](https://github.com/langningchen/cph-ng/discussions/285) for background. As announced, contributions to the Rust rewrite are welcome; acceptance of unrelated PRs will resume after a separate announcement.
